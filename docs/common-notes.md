# 全フェーズ共通の注意点

未経験者の事故とつまずきの多くは、**課金・秘密情報・環境差分** の3つから起きます。学習を始める前に必ず読んでください。
特にクラウドを扱うフェーズ6・11・12の前には、もう一度読み返してください。

## 1. 課金事故の防止

クラウドは「使った分だけ課金される」仕組みです。作ったリソースを消し忘れると、使っていなくても料金が発生し続けます。

- クラウドのアカウントを作成したら、**最初に予算アラート**(例:月1,000円)を設定する
- 各フェーズのハンズオンの最後にある「後片付け」の手順を必ず実行する
- 無料枠には条件(リージョン・マシンサイズ・期間)があるため、教材で指定された設定から変更しない
- 不安なときは、クラウドのコンソールで「現在動いているリソース」と「今月の請求額」を確認する習慣をつける

## 2. 秘密情報の管理

パスワード・APIキー・`SECRET_KEY` などの秘密情報がGitHubに公開されると、数分で悪用されることがあります。

- 秘密情報はコードに直接書かず、`.env` ファイルや環境変数で管理する
- `.env` は必ず `.gitignore` に追加する(代わりに `.env.example` を用意する)
- `git add .` の前に `git status` で、追加されるファイルを確認する
- 万が一pushしてしまった場合は、**履歴を消すだけでは不十分**。すぐにそのキーを無効化し、新しいキーを発行する
- クラウドのrootアカウント(最初に作ったアカウント)は日常的に使わず、多要素認証(MFA)を設定する

## 3. つまずき対策

### エラーが出たときの手順

1. エラーメッセージの **最後の行** を読む(Pythonの場合、原因は最後に書かれていることが多い)
2. エラーが出たファイル名と行番号を確認する
3. エラーメッセージをそのまま検索する
4. 公式ドキュメントを確認する
5. それでも解決しない場合は、「やったこと・期待した結果・実際の結果・エラー全文」をまとめて質問する

### よくあるエラー

| エラー・症状 | よくある原因 | 対処 |
| --- | --- | --- |
| `command not found` | インストールされていない、またはPATHが通っていない | インストールを確認し、ターミナルを再起動する |
| `ModuleNotFoundError` | 仮想環境(venv)が有効になっていない | `source .venv/bin/activate` を実行する |
| `zsh: command not found: python` | Macには `python` コマンドがない | 仮想環境を有効にするか、`python3.12` を使う |
| `xcrun: error: invalid active developer path` | macOSのアップデートで Command Line Tools が外れた | `xcode-select --install` |
| `Address already in use` | 同じポートを別のプロセスが使っている | 前に起動したサーバーを `control + C` で止める。5000番はAirPlayが使っているので5001番を使う |
| `Permission denied` | 権限が足りない | ファイルの権限や、`sudo` が必要な操作か確認する |
| ブラウザで変更が反映されない | キャッシュ、またはサーバーの再起動忘れ | スーパーリロード(`command + shift + R`)、サーバー再起動 |

### Macを使う上での注意

この教材は **Mac(macOS)** を前提にしています。

| 項目 | 内容 |
| --- | --- |
| キー操作 | ターミナルでのプログラムの停止は `control + C`(`command` ではない)。ブラウザやエディタのショートカットは `command` を使う |
| Python | 仮想環境は必ず `python3.12 -m venv .venv` で作る。Mac標準の `python3` は古い場合がある |
| ポート5000番 | AirPlay レシーバーが使っているため、Flask は `--port 5001` で起動する |
| 隠しファイル | `.gitignore` や `.env` は Finder で見えない。`command + shift + .` で表示を切り替えられる |
| チップ | Apple シリコン(M1以降)と Intel で、Homebrew の場所や Docker イメージの種類が異なる(フェーズ0・9・11で説明) |
| シェル | ターミナルのシェルは zsh。設定ファイルは `~/.zshrc` と `~/.zprofile` |

### 途中から再開したいとき

各フェーズの `sample/` に、そのフェーズを終えた時点のコードが入っています。
詰まって先に進めない場合は、前フェーズの `sample/` を自分のリポジトリにコピーして再開してください。
